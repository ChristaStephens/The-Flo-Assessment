## Brand foundation

- Purpose: Make more time for what matters.
- Mission: Make work flow better, so people can focus on what matters.
- Brand promise: Less Work. More Flow.
- Brand question: What would you do with more time?
- Method: Discover → Diagnose → Test → Expand → Manage.
- Design personality: professional, clean, modern, efficient, and reliable.

## Font note

The supplied guide names Better Sabrina as an accent font for numbers and key figures. No loadable font file was supplied, so the portable token set uses Montserrat and Spectral; Better Sabrina remains a documented optional licensed accent rather than being silently substituted.
